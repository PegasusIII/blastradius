PHP2Shell and the eMudhra root removal: which of your hosts are exposed, and what do you fix first?

BlastRadius is a free, read-only shell script. Run it as a normal user and you get one verdict per host (PATCH FIRST, ROTATE FIRST or OK) plus the exact commands for your distro. It never changes anything on the host and it doesn't phone home.

curl -fsSLO https://github.com/OWNER/blastradius/releases/latest/download/blastradius.tar.gz   # placeholder, not live
tar xzf blastradius.tar.gz && sh blastradius/bin/blastradius

What it checks that outside-in monitors can't see

Every PHP build
CLI, FPM, CGI and mod_php, with version and SAPI, against the fixed versions 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35.
Trust stores
The OS bundle, Python certifi and Java cacerts, checked for distrusted roots by fingerprint. The Node version is reported, and you get a note for Go/rustls.
Certs you didn't issue
Leaf certs referenced by nginx, Apache, HAProxy and Postfix that chain to a distrusted CA.
Safe to run
Read-only, no root, no network, signed definitions, MIT licensed. Fix commands are printed, never run.
